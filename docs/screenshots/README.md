# Public screenshots and media

The files under `1.2.4-912/` are the small, owner-approved public demo set
already used by the Hermes Console website and Google Play presentation. The
README intentionally reuses only Home, Conversations, Voice and Tools so the
repository stays clear and compact.

Only add or replace media when it meets all of these conditions:

- captured from the isolated emulator with the approved fictional dataset;
- English-only visual copy;
- no pairing QR/link, token, host, private address, device name or notification;
- reviewed at full resolution before being versioned;
- authorized by the owner for its stated public surface.

Do not silently replace these files with fresh emulator or device captures.
New media must pass the same privacy and full-resolution review gate first.
